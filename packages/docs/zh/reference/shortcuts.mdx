工具和编辑快捷键在项目打开、且输入框、文本区域或可编辑文本区域未获得焦点时生效。

{/* Booharu: tool keys from a focused slider. */}

<Note>
  在 Booharu
  中，当滑块、复选框等不输入文字的输入控件获得焦点时（例如拖动滑块之后），工具按键仍会切换工具。`Space`、方向键、`Enter`、`Delete`、`Escape`
  以及带 `Ctrl`、`Command` 或 `Alt` 的快捷键仍由滑块接收。
</Note>

## 工具

| 工具     | 按键 |
| -------- | ---- |
| 选择     | `V`  |
| 直接选择 | `A`  |
| 矩形选框 | `M`  |
| 套索     | `L`  |
| 文本     | `T`  |
| 文本块   | `K`  |
| 绘画     | `B`  |
| 橡皮擦   | `E`  |
| 取色器   | `I`  |
| 移除     | `J`  |
| 平移     | `H`  |

每个按键都与 Photoshop 中同一工具的按键相同，**文本块**使用其图框工具的按键。

{/* Booharu: [ and ] for brush size. */}

<Note>
  在 Booharu 中，与 Photoshop 相同，使用绘画、橡皮擦或移除工具时，按 `[` 缩小画笔，按 `]`
  放大画笔，每按一次约改变当前大小的十分之一。这三个工具各自保留自己的画笔大小。如果键盘布局没有方括号键，请使用
  `P` 右侧的两个键，或用 `AltGr`
  输入方括号。对话框或弹出面板（包括画笔大小面板）打开时，这两个键不起作用。
</Note>

## 导航

| 操作                                   | 手势                                      |
| -------------------------------------- | ----------------------------------------- |
| 临时平移                               | 按住 `Space` 或鼠标中键拖动               |
| 平移                                   | 滚动；`Shift` + 滚动可水平平移            |
| 围绕指针缩放                           | `Ctrl` 或 `Command` + 滚动，或双指捏合    |
| 调整画笔大小                           | 在绘画、橡皮擦或移除工具下按 `Alt` + 滚动 |
| 清除选择                               | `Escape`                                  |
| 适应当前页面                           | `Ctrl+0` 或 `Command+0`                   |
| 显示原图                               | `\`                                       |
| 在图层和故事之间切换（输入框中也可用） | `F7`                                      |

松开 `Space` 后会回到原来使用的工具。

## 编辑

| 操作                                 | Windows / Linux         | macOS                   |
| ------------------------------------ | ----------------------- | ----------------------- |
| 撤销                                 | `Ctrl+Z`                | `Command+Z`             |
| 重做                                 | `Ctrl+Shift+Z`          | `Command+Shift+Z`       |
| 选择页面上的所有图层                 | `Ctrl+A`                | `Command+A`             |
| 取消矩形选框或套索的选区             | `Ctrl+D`                | `Command+D`             |
| 删除所选图层，或用直接选择选中的锚点 | `Delete` 或 `Backspace` | `Delete` 或 `Backspace` |
| 提交在画布上输入的文字               | `Ctrl+Enter`            | `Command+Enter`         |

{/* Booharu: Escape keeps what's typed. */}

<Note>
  在 Booharu 中，按 `Escape`
  也会提交在画布上输入的文字，与文字旁工具条上的**完成**相同，误按也不会丢失输入的内容。输入法正在组字时，`Escape`
  只取消组字。
</Note>

{/* Booharu: right-click a box. */}

<Note>
  在 Booharu
  中，使用选择、直接选择或文本工具在页面上右键单击文字或文本块，会在指针处打开它的文本框操作，与**编辑**菜单中的相同，例如
  **FX…**、**重新翻译**和**文本框详情**。若它尚未被选中，会先选中它，因此在选中的多个文本框中右键单击时，选择保持不变。用方向键和
  `Enter` 选择操作，按 `Escape` 关闭菜单。
</Note>

## 阅读

在**阅读**模式下：

| 操作               | 按键                                                            |
| ------------------ | --------------------------------------------------------------- |
| 下一页或下一组跨页 | 从右到左时按 `←`，从左到右时按 `→`；`↓`、`Page Down` 或 `Space` |
| 上一页或上一组跨页 | 从右到左时按 `→`，从左到右时按 `←`；`↑` 或 `Page Up`            |
| 第一页或最后一页   | `Home` 或 `End`                                                 |
| 用指针翻页         | 点击要翻向的那半边页面，或向下滚动前进                          |

快捷键只影响桌面界面，不影响导出的页面。
