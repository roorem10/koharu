ツールと編集のショートカットは、プロジェクトを開いていて、入力欄、テキストエリア、編集可能なテキスト領域にフォーカスがないときに使えます。

{/* Booharu: tool keys from a focused slider. */}

<Note>
  Booharu
  では、スライダーやチェックボックスなど、文字を入力しない入力欄にフォーカスがあるとき（スライダーをドラッグした後など）も、ツールのキーでツールを切り替えられます。`Space`、矢印キー、`Enter`、`Delete`、`Escape`、`Ctrl`・`Command`・`Alt`
  を使うショートカットは、その入力欄が受け取ります。
</Note>

## ツール

| ツール         | キー |
| -------------- | ---- |
| 選択           | `V`  |
| パス選択       | `A`  |
| 長方形選択     | `M`  |
| なげなわ       | `L`  |
| テキスト       | `T`  |
| 描画           | `B`  |
| 消しゴム       | `E`  |
| カラーピッカー | `I`  |
| 削除           | `J`  |
| 移動           | `H`  |

キーは Photoshop の同じツールのものです。

{/* Booharu: the O tool. */}

<Note>
  Booharu
  には**OCRボックス**ツール（`O`）があります。自動処理で拾われなかった行をボックスで囲むと、テキストブロックになって
  OCR され、**設定 → パイプライン**の既定の操作に応じて翻訳・クリーンアップされます。`Alt`
  を押しながら離すと OCR のみ、`Shift` を押しながら離すと OCR・翻訳・クリーンアップを行います。
</Note>

## 移動

| 操作                         | ジェスチャー                                       |
| ---------------------------- | -------------------------------------------------- |
| 一時的に移動                 | `Space` または中ボタンを押しながらドラッグ         |
| 移動                         | スクロール。`Shift` + スクロールで横方向           |
| ポインター位置で拡大縮小     | `Ctrl` または `Command` + スクロール、またはピンチ |
| ブラシサイズを変更           | 描画、消しゴム、削除で `Alt` + スクロール          |
| 選択を解除                   | `Escape`                                           |
| アクティブなページを全体表示 | `Ctrl+0` または `Command+0`                        |

`Space` を離すと、使っていたツールに戻ります。

## 編集

| 操作                                                   | Windows / Linux             | macOS                       |
| ------------------------------------------------------ | --------------------------- | --------------------------- |
| 元に戻す                                               | `Ctrl+Z`                    | `Command+Z`                 |
| やり直す                                               | `Ctrl+Shift+Z`              | `Command+Shift+Z`           |
| ページのすべてのレイヤーを選択                         | `Ctrl+A`                    | `Command+A`                 |
| 長方形選択やなげなわの選択を解除                       | `Ctrl+D`                    | `Command+D`                 |
| 選択したレイヤー、またはパス選択で選んだアンカーを削除 | `Delete` または `Backspace` | `Delete` または `Backspace` |
| キャンバスで入力したテキストを確定                     | `Ctrl+Enter`                | `Command+Enter`             |

ショートカットはデスクトップの操作に影響し、書き出すページには影響しません。
