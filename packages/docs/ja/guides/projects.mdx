プロジェクトは元画像、テキスト、画像の編集、レイアウトを保持します。Koharu は各プロジェクトを 1 つの `.khr` ファイルに保存し、読み込んだファイル自体は変更しません。編集はその都度保存されるため、**保存**コマンドはありません。

## プロジェクトの作成と再開

スタート画面には Koharu のプロジェクトフォルダー内のプロジェクトが、最近変更した順に表示されます。

| プラットフォーム | プロジェクトフォルダー                          |
| ---------------- | ----------------------------------------------- |
| Windows          | Koharu のインストールフォルダー内の `projects`  |
| macOS            | `~/Library/Application Support/Koharu/projects` |
| Linux            | `~/.local/share/Koharu/projects`                |

ここでプロジェクトを作成、開く、削除できます。プロジェクト名はファイル名になるため、どのプラットフォームでもファイル名として使えない名前は拒否されます。**ファイル → プロジェクトを閉じる**でスタート画面に戻ります。

<Warning>
  プロジェクトを削除すると、確認後にそのファイルが完全に削除されます。元に戻すことはできません。
</Warning>

## ページを読み込む

<Steps>
  <Step title='ファイルまたはフォルダーを選ぶ'>
    **ファイル → ページを読み込む → ファイル…** で画像、アーカイブ、PDF を選びます。**フォルダー…**
    を選ぶと、フォルダーの直下にある対応ファイルを読み込みます。サブフォルダーは検索しません。
  </Step>
  <Step title='読み込み順を確認する'>
    ファイルとアーカイブ内の項目は、数字を値として比較する名前順に並びます。`page2.png` は
    `page10.png` より前です。PDF
    のページは文書の順序を保ちます。新しいページはプロジェクトの最後のページの後に追加されます。
  </Step>
  <Step title='ページ一覧を整理する'>
    `Ctrl`、`Command`、`Shift`
    でページを選択し、ドラッグで並べ替え、操作メニューから削除します。削除は元に戻せます。ページの順序が処理と書き出しの順序になります。
  </Step>
</Steps>

| 入力                               | 読み込み結果                                                  |
| ---------------------------------- | ------------------------------------------------------------- |
| PNG、JPEG（`.jpg`、`.jpeg`）、WebP | 画像 1 枚につき 1 ページ                                      |
| ZIP、CBZ、RAR、CBR                 | PNG、JPEG、WebP の項目ごとに 1 ページ。その他の項目はスキップ |
| PDF                                | 文書の各ページを 300 DPI で描画して 1 ページ                  |

macOS の `__MACOSX` リソースフォークなど、OS がアーカイブに残すファイルはスキップされます。読み込んだデータはプロジェクトファイルにコピーされるため、元ファイルを移動・削除してもプロジェクトには影響しません。

  Booharu
  では、ページの操作メニューの**ページのレベルを補正…**で、検出の前にスキャンのレベルを補正できます。対象はそのページで、そのページが選択に含まれていれば選択したすべてのページです。**編集
  →
  ページのレベルを補正…**では、すべてのページが対象の状態で開きます。**自動レベル補正**は、**両端のクリップ量（%）**の分の画素を両端で除いたうえで、スキャンのいちばん暗いインクを黒に、いちばん明るい紙を白に引き伸ばします。**紙を白くする**は、しきい値より明るい紙を白にします。ダイアログでは最初のページの補正前と補正後をプレビューでき、値は**設定
  → パイプライン → ページのレベル補正**の値から始まります。1 回の補正は 1
  回の取り消しで元に戻せます。クリーンアップやインペイントが済んだページはスキップします。補正したページは、読み込んだときのスキャンを非表示でロックされた**元のスキャン**レイヤーに保持します。このレイヤーは**すべてのレイヤーを選択**と
  PSD
  の書き出しの対象外で、ページの操作メニューの**元のスキャンに戻す**で元に戻せます。補正済みのページをもう一度補正すると、補正後のスキャンにさらに補正がかかるので、弱い値を試すときは先に元のスキャンに戻してください。
</Note>

## バックアップと復元

プロジェクトを閉じてから、その `.khr` ファイルをコピーします。復元するときは Koharu を終了し、ファイルをプロジェクトフォルダーに戻します。

<Note>
  プロジェクトを閉じても作業内容はすべて残りますが、取り消しとやり直しの履歴は消えます。1
  つのプロジェクトを同時に開けるのは 1 つのウィンドウだけです。
</Note>
