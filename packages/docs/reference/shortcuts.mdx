Tool and editing shortcuts apply while a project is open and an input, textarea, or editable text region is not focused.

{/* Booharu: tool keys from a focused slider. */}

<Note>
  In Booharu, a tool's key still switches tools while a slider, checkbox, or other input that
  doesn't take text is focused, such as after you drag a slider. A slider keeps `Space`, the arrows,
  `Enter`, `Delete`, `Escape`, and shortcuts with `Ctrl`, `Command`, or `Alt`.
</Note>

## Tools

| Tool                | Key |
| ------------------- | --- |
| Select              | `V` |
| Direct Selection    | `A` |
| Rectangular Marquee | `M` |
| Lasso               | `L` |
| Text                | `T` |
| Text block          | `K` |
| Brush               | `B` |
| Eraser              | `E` |
| Color picker        | `I` |
| Remove              | `J` |
| Pan                 | `H` |

Each key is Photoshop's for the same tool, and **Text block** has its Frame tool's.

{/* Booharu: [ and ] for brush size. */}

<Note>
  In Booharu, as in Photoshop, `[` makes the brush smaller and `]` makes it larger with Brush,
  Eraser, or Remove, each press by about a tenth of its size. Each of the three tools keeps its own
  size. On a keyboard layout without bracket keys, use the two keys to the right of `P`, or type the
  brackets with `AltGr`. The keys do nothing while a dialog or popover is open, the brush size
  popover included.
</Note>

## Navigation

| Action                                            | Gesture                                      |
| ------------------------------------------------- | -------------------------------------------- |
| Pan temporarily                                   | Hold `Space` or the middle button and drag   |
| Pan                                               | Scroll; `Shift` + scroll pans horizontally   |
| Zoom at the pointer                               | `Ctrl` or `Command` + scroll, or pinch       |
| Change brush size                                 | `Alt` + scroll with Brush, Eraser, or Remove |
| Clear the selection                               | `Escape`                                     |
| Fit the active page                               | `Ctrl+0` or `Command+0`                      |
| Show the original page                            | `\`                                          |
| Switch between Layers and Story, from a field too | `F7`                                         |

Releasing `Space` returns to the tool you were using.

## Editing

| Action                                                              | Windows / Linux         | macOS                   |
| ------------------------------------------------------------------- | ----------------------- | ----------------------- |
| Undo                                                                | `Ctrl+Z`                | `Command+Z`             |
| Redo                                                                | `Ctrl+Shift+Z`          | `Command+Shift+Z`       |
| Select all layers on the page                                       | `Ctrl+A`                | `Command+A`             |
| Deselect the area marked with Rectangular Marquee or Lasso          | `Ctrl+D`                | `Command+D`             |
| Delete selected layers, or the anchors picked with Direct Selection | `Delete` or `Backspace` | `Delete` or `Backspace` |
| Commit text typed on the canvas                                     | `Ctrl+Enter`            | `Command+Enter`         |

{/* Booharu: Escape keeps what's typed. */}

<Note>
  In Booharu, `Escape` also commits text typed on the canvas, as **Done** in the bar beside the text
  does, so a stray key never loses it. While an input method is composing, `Escape` cancels only the
  composition.
</Note>

{/* Booharu: right-click a box. */}

<Note>
  In Booharu, right-clicking a text or a text block on the page with Select, Direct Selection, or
  Text opens its box actions at the pointer, the same ones as the **Edit** menu, such as **FX…**,
  **Translate again**, and **Box details**. The box is selected first unless it already is, so a
  right-click inside a selection of several boxes keeps them all. Use the arrows and `Enter` to pick
  an action, and `Escape` to close the menu.
</Note>

## Reader

In **Read** mode:

| Action                  | Keys                                                                    |
| ----------------------- | ----------------------------------------------------------------------- |
| Next page or spread     | `←` right to left, `→` left to right; `↓`, `Page Down`, or `Space`      |
| Previous page or spread | `→` right to left, `←` left to right; `↑` or `Page Up`                  |
| First or last page      | `Home` or `End`                                                         |
| Turn with the pointer   | Click the half of the page to turn toward, or scroll down to go forward |

Shortcuts affect the desktop interface, not the exported page.
