# WO-42: Use the Booharu name in the remaining interface strings

The app's title bar and About dialog were moved to the Booharu name in WO-25 on another branch. About 15 strings in `packages/koharu/public/locales/en-US/translation.json` still say "Koharu" (Agent tab prompts, "Koharu canvas", fatal error title, font fallback text, "Koharu project", "Opening Koharu…", "Preparing Koharu", update dialog, and so on).

1. Change user-visible "Koharu" to "Booharu" in `en-US`, and the same word in every other locale folder.
2. Keep "Koharu" where it refers to the upstream project itself rather than this app (for example a line saying the fork is based on Koharu, or credits), and where the string is not a product name. List what you left and why.
3. Check the agent's system prompt or tool descriptions and other native user-visible text that say Koharu (`run_pipeline` description, and so on). Change model-facing product names only where they'd confuse the user-visible Agent's self-description. Don't rename any code identifier, crate, package, file format, folder, config key or credential namespace.
4. No agent action needed (no new feature). Fix any test that locks the old name, by the smallest edit; don't add tests for phrases.
5. Run the relevant localization test.
