# WO-35: Second pass on hard lines (puns, names, wordplay) (issue #62, goal #54)

The slowest manual step is copying hard lines (puns, Japanese wordplay, fantasy terms, pronoun choices) with the page into ChatGPT in a browser and pasting the result back. Give those lines the same care inside the app. Read chapter already notes likely puns, and **Explain this line** (WO-18) gives reasoning and alternatives when pressed.

Read first: the Explain request and card (`commands/context/`, `components/editor/LineContextCard.tsx`), `commands/context.rs`, provider and structured-output code in `koharu-translator`, `commands/qc.rs`.

Build:

1. **Which lines are hard** (pure, tested function): a pun note, a name or term that isn't in the glossary, or a QC flag.
2. **Request:** one extra request per hard line, reusing the Explain request's path and its structured output: sends the page or a crop, the line, the brief, the characters and the glossary, and asks for the best wording, two alternatives and a one-line reason.
3. **Setting:** optional **Model for hard lines**, so a stronger model is used only where it matters. Default is the normal translation model.
4. **Result:** the best wording replaces the translation unless it was hand-edited. Marked "second pass" with the earlier wording one click away. Alternatives show in the Explain card with **Use this**. One undo step per line or per page, whichever matches existing translation commits.
5. New names or terms it settles on become glossary suggestions.
6. **Entry points:** a **Second pass** button on a box, and one for all lines with a pun note or all hard lines, as a normal job with existing progress and stop. Expose a function for the auto-run recipe at quality Best (a sibling branch owns it; don't wire it).
7. **Agent action:** run the second pass on chosen boxes.
