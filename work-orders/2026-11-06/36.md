# WO-36: Match the original lettering, parts A, B and D (issue #52, upstream 1252, goal #54)

Translated text should stay faithful to the original lettering: if a bubble in the raw is bold, or clearly differs from the rest of the page, the result should pick that up. Priority for each box: hand edits > match the original > AI emphasis > category defaults from Settings. Part C (word-level bold carry-over) is NOT in this work order.

Read first: `commands/lettering.rs` (`resolve_category`), `crates/booharu-context/src/lettering.rs`, bubble-shape measurement, detection text mask storage, YuzuMarker in `koharu-ml`, `components/editor/LetteringCategoryLine.tsx`, `TypesettingPreferences.tsx`.

## Part A: read the source lettering

Measure per box: stroke thickness relative to letter height from the detection text mask, plus ink density. Compare with the page's usual lettering (median of the page's dialogue boxes), not a fixed number, so a page that's bold everywhere doesn't turn every box into Shout. Result: `source_bold` (yes, no, unsure) and `source_different`. Unsure records nothing. Stored in the project sidecar like WO-18 labels. Measurement and comparison are pure functions with tests on synthetic masks (thin text, thick text, noisy screentone).

## Part B: combine signals for Shout and bold

`resolve_category` is a ladder today. For Shout/bold, count three signals: source bold, jagged or spiky bubble, and a yelling line (Read chapter label Shout or Weak Shout). 3 of 3: Shout + bold always. 2 of 3: Shout + bold (default). 1 of 3: normal category, same as today. Setting in Settings > Typesetting: **Signals needed for Shout** 1, 2 or 3 (default 2). A box with `source_different` but not bold gets the closest category (thin or shaky to Whisper or Crying, heavy to Shout), never an exact font. The Inspector shows why a box got its style ("Shout: bold original + spiky bubble"). Hand-styled boxes are never changed; restyling is one undo step, as in WO-19. Test 1/2/3 signals and hand-edit protection.

## Part D: font coverage check

Before a category font is applied, check it has every character of the translated text. If not, use the next fitting category font (or the default) for the whole box, instead of the renderer swapping fonts per character.

## Agent action

Read a box's source-style result and why it got its style (read-only; also in MCP read-only mode).
