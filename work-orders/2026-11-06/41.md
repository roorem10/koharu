# WO-41: Small editor ideas: recent colors, layer toggle keys, canvas background, live font preview (issue #37)

Four small parked features, one coherent commit-sized piece each. Match Photoshop or Clip Studio Paint where unspecified.

1. **Recent color history** in the color picker (upstream #1015; idea from NeKoharu `90321acf` by nekojin116). Shows the last 10 or so committed colors, persisted per app. Committed only on the color being applied, not during dragging. Reuses the existing numeric color representation (AGENTS.md).
2. **Keys to toggle layers quickly** (upstream #726): shortcuts for showing or hiding Text, Cleanup and Original layers, in the existing shortcut system and listed in Shortcut preferences. Doesn't steal keys from focused controls. Uses the existing visibility edit and undo.
3. **Canvas background color** in light and dark mode (upstream #940): a preference for the color around the page. Presentation only; not exported.
4. **Live font preview** while arrowing through the font picker. NeKoharu `2a5707a5` made one undo step per arrow press, which must not happen: the preview is transient, committing happens only on selection (Enter or click), and Escape restores. AGENTS.md says commit on selection, not on focus or hover. The preview should go through the existing transient path if there is one; if it can't be done without durable edits, leave this item out and explain why.

Agent actions: toggling layer visibility is already covered by `set_visibility`; the others are UI preferences, so state in your summary why no action is needed, or add a small settings action if one obviously fits.
