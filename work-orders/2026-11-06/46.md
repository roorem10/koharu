# WO-46: Find and fix what makes SFX subtitles feel glitchy

Noted during 0.0.3 testing: SFX subtitles (WO-07, **Add SFX subtitle**) feel glitchy. No precise report exists, so this is a bug hunt by reading.

Read first: `crates/koharu-app/src/commands/ocr_box.rs`, `commands/lettering.rs`, `components/ocr-box/*`, `components/text-extras/*`, `components/editor/BoxActions.tsx`, the bubble flow code in `koharu-renderer/src/renderer.rs`, the subtitle style in Settings.

Do:

1. Trace the whole path of adding a subtitle: selection, command, commit, what the canvas shows, how it's placed relative to the SFX box, how it's sized, whether it flows into a bubble it shouldn't, what happens on undo, redo, a second press, moving or deleting the SFX, or re-running translation or cleanup.
2. Fix each real defect you find: placement off the page, flicker, extra commits making more than one undo step, selection jumping, a duplicate subtitle on a second press, a stale overlay, style not applied until a refresh. Add a test for each fix where the code has a test harness for it.
3. Don't redesign the feature or change the subtitle style's settings.
4. In your summary, list each defect with its cause and fix, and also what you looked at and found correct.
