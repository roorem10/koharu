# WO-44: Carry bold words from the original into the translation (issue #52 part C, goal #54)

If some words inside a bubble are bold in the raw, the matching translated words should be bold. Measuring alone can't do it since word order changes in translation, but the translation model can. Rich text (0.0.3) and AI emphasis (WO-11F) already exist. Parts A, B and D of #52 are on a sibling branch; this work order does not depend on them, so include a small self-contained per-line stroke measurement only if nothing suitable exists on this base.

Read first: `crates/koharu-pipeline/src/emphasis.rs`, `commands/emphasis.rs` and `commands/emphasis/`, `koharu-pipeline/src/stages/translation.rs`, `crates/koharu-translator`, `commands/rich_text.rs`.

Build:

1. With a vision model, the translate request also sends the box crop and the source words or lines marked as bold, through the existing single translation path and its structured output. The model returns which translated words carry that emphasis, using the word-style output AI emphasis already uses. With nothing marked or no vision model, the request stays byte-for-byte as today; add a test for that.
2. The result lands as normal per-word bold, tagged "from original" so it's kept apart from AI-added emphasis, and both stay editable. Priority: hand edits > from original > AI emphasis > category defaults.
3. Setting to switch it off, on by default when a vision model is set, in Translation preferences.
4. Agent action: read a box's emphasis sources (from original, AI, hand).
