1. **Koharu name at first launch:** the window title and the loading screen ("Preparing Koharu") say Koharu, which confuses people trying the fork. Already fixed on branches not in the test build: `wo-25-booharu-name` (title bar, About) and `wo-42-booharu-strings` (loading screen and other strings).
2. **New series from the home page:** the new-project series picker can only choose an existing series, so the first chapter of a new series has nowhere to go. Code is on `wo-27-ready-check` (ddd81877), kept out of the test build, and a cloud thread filed the issue on 2026-11-06.
3. **Two Run buttons:** decided to have one Run button for both auto runs and user-defined runs, with stages switched on or off in the menu beside Run. See [[codex-run-2026-11-06]].
4. **Run presets:** both default presets showed all four stages ticked; waiting on Riley to confirm whether this is a bug.
5. **Ready check Fix:** a Fix button "does nothing visibly"; waiting on which row.
6. **QC fix pass error** ("committer did not advance the scene revision"): fixed in build 5 (wo-28 e12d5df4). The automatic fix pass after Auto run uses model requests the estimate doesn't count; proposed making it a real Auto run step.
7. **Yellow Ready check in a blank project:** the amber "Ready check" button in the title bar stands out in an empty new project and may confuse new users. Note only; Riley asked not to change it yet.
8. **Join text in the same bubble (WO-20):** Riley wants it off by default, and ideally removed. One bubble shape can hold two separate lines, and automatic joining has only given bad results; manual join from the right-click menu stays. The code joins by detected bubble shape alone (no vision model; `join_in_bubble`, default true, in koharu-pipeline stages/detection.rs). Note only; Auto run step 2 also assumes joining.
9. **Default font and Ready check fonts:** the default text font should be CC Wild Words ("CCWILDWORDS") so users don't have to set it first. Ready check must not warn when lettering categories fall back to the default font: using one font for everything is fine, and category fonts are optional customization. CC Wild Words is in the built-in font catalog, which downloads on first use, so it can be the default for everyone. Note only.
10. **Default text color:** should start as pure black #000000 so users never have to set it; still changeable. Check how this interacts with the existing "detect text colors" option, which copies colors from the original. Note only.
11. **Lettering categories settings are cumbersome:** one long scrolling list of 15 categories with dropdowns for each. Proposed: show only categories that differ from the default, with an "Add a style for..." picker, grouped and with a preview line; possibly a compact table. Agreed plan (2026-11-07): Riley sends a list of categories and fonts, which become the shipped defaults (take them from the built-in catalog of about 640 downloadable families from mayocream/fonts, which includes CC Wild Words, Anime Ace 2.0 BB, MangaMaster Pro BB, Palooka BB and BadaBoom BB, using the catalog's own names; only fonts outside the catalog need a fallback). Known bug, now in #95: font suggestions only list fonts installed in Windows. Settings get a searchable category picker; choosing a category shows its font dropdown plus bold and italic, like the current controls. Riley's list arrived 2026-11-07 as koharu-manga-font-category-guide.md: 242 detailed categories over 81 catalog families, plus 12 core presets. Proposed defaults for the app's 15 categories: normal_dialogue CCWildWords Regular; thoughts Anime Ace 2.0 BB Italic; floating augie Regular; small_text MangaMaster Pro BB Regular; narration_box CC Meanwhile Regular; shout Palooka BB Italic; weak_shout CCWildWords Bold Italic; sfx OneTwoPunch BB Regular; moan MumbleGrumble II BB Regular; title Edo Regular; phone_text MangaMaster Pro BB Regular; whisper CCWildWords Italic; shy augie Regular; crying CCWildWords Italic; menacing CryptCreep BB Regular. Core presets with no app category: extreme shouting (BadaBoom BB), handwritten notes (Komika Hand), machine speech (Mainframe BB). Riley approved this mapping (2026-11-08), including weak_shout, shy and crying. Proposed new categories: handwritten (Komika Hand), sign or printed text (Futura LT Medium), electronic voice (Mainframe BB). Advised against extreme shout (use Shout plus size) and translator note (an app style, not something detected). Riley approved all three new categories (2026-11-08), making 18.
12. **Canvas bar layout:** move "Check cleanup" and "Show original" from the right of the canvas top bar (beside Auto run and the model picker) to the left end of that same bar, above the canvas. Note only.
