# WO-37: Final look check of each finished page (issue #63, goal #54)

Some problems only show on the finished page: a missed bubble (untranslated text in the final page), cleanup marks, text cut off or covering art, text hard to read on busy art. QC only checks each box.

Read first: `commands/qc.rs`, `components/qc/*`, how Read chapter sends images to a vision model with structured output (`commands/context/reading.rs`), `koharu-desktop` frame rendering and `commands/output.rs`, `commands/ocr_box.rs`.

Build:

1. **Page check:** render the finished page from the one prepared frame and send it with the original to the vision model, using native structured output. Ask for problems with rough locations: untranslated text left, missed bubbles or SFX, cleanup marks, text cut off or overlapping art, hard-to-read text, wrong reading order.
2. **Results** land in QC as **Page check** items with the area outlined. Clicking jumps to it. Stored in the sidecar.
3. **Fixes only on a concrete match** (pure, tested function): a fix runs only when the model's area matches something concrete, such as a detected text area. Otherwise the item is only listed. Hard-to-read text over art gets the free-text outline style, unless hand-styled. Missed text gets an OCR box, translation and typesetting, following the SFX setting. Keep the first version simple: if a fix can't be done reliably, list it.
4. **Entry points:** a **Check page** button for a page or all pages, as a normal job. Off by default. Costs one request per page, which the confirm states. Expose a function for the auto-run recipe at quality Best (a sibling branch owns it; don't wire it).
5. No vision model: skipped with a clear reason.
6. **Agent action:** run the page check on chosen pages, and read results (the read works in read-only mode).
