# WO-50: Pattern fills and Mesh Warp for text (issue #37)

Two parked optional features for hand typesetters. Do pattern fills first; do Mesh Warp only if it can be done properly within this work order, and say so if not. Match Photoshop or Clip Studio Paint where unspecified.

**Pattern fills:** a text fill mode beside solid and gradient, using an image pattern the user picks (PNG or JPEG), with scale and offset. Stored through the existing Typography fill and asset path, or the `extensions` map if there's no fill variant to extend. One prepared frame feeds canvas, PNG, crops and PSD, so the pattern goes through the rasterizer path in `koharu-rasterizer`/`koharu-renderer`; WebGPU presentation must match. Project stays portable, so the pattern is stored as a project blob and not a file path. If this needs a save-format change, stop, and leave it out with the reason.

**Mesh Warp** (builds on WO-10, `commands/warp.rs`, `components/warp/*`, `WarpHandles.tsx`): an adjustable grid over a selected text box; drag nodes for local bends. Commit on drag end as one undo step. Mesh data lives in the same storage as the existing warp. Canvas, PNG, crops and PSD agree. Reset and cancel like the perspective warp.

Agent action for each: extend `set_typography` or the warp tool if one was added on this base, and otherwise add a small tool. Tests: the mesh interpolation as a pure function, and pattern tile sampling.
