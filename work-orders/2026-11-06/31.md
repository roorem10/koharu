# WO-31: SFX handling (subtitles, only SFX that matter) (issue #61, goal #54)

Usually SFX are left alone, and only the ones that matter or sit inside bubbles get translated. The run has to make that call by itself, and it must never erase an SFX it isn't going to replace.

Read first: `commands/lettering.rs`, `commands/lettering/settings.rs`, `SfxPreferences.tsx`, `commands/ocr_box.rs` (Add SFX subtitle, WO-07), `koharu-pipeline/src/stages/detection.rs` (`write_mask`), `commands/context/reading.rs`.

Build:

1. **Check this first:** the cleanup mask is built from all text detections. Confirm whether skipped SFX get erased today. If they do, keep skipped and subtitled SFX out of the cleanup mask so the original art stays. This is the highest-value part of this WO. Note that the mask is written at detection, and lettering labels only arrive with Read chapter, so work out the correct place to apply this (for example at the inpainting stage, using current labels) and test the decision as a pure function.
2. **Split the setting in two** (replace the old field; no compatibility layer beyond the settings loader's normal handling):
   - SFX inside bubbles: **Translate** (default) / Skip
   - SFX outside bubbles: **Skip** (default) / Subtitle / Replace
3. **Subtitle:** the run adds the WO-07 subtitle beside each SFX it keeps, in the subtitle style from Settings. Running again doesn't add a second subtitle.
4. **Only SFX that matter:** Read chapter marks an SFX as important when the story depends on it (a knock someone answers, a phone that rings), as an optional field in the reading schema and sidecar. Option in the SFX settings: apply the outside-bubble action only to the important ones.
5. **Hand edits win:** a hand-set category or per-box choice always beats the settings.
6. **Agent action:** set how one box's SFX is handled (skip, subtitle, translate).
