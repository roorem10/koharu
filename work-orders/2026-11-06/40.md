# WO-40: Copy and paste text boxes (issue #37, upstream #548 and #1057)

For repeated hand-made lettering (a recurring SFX, sign or caption): copy text boxes with their text, style and position, and paste on the same page or another page. Match Photoshop or Clip Studio Paint where unspecified.

Credit in code comment where anything is borrowed: NeKoharu `98bb6f0e` (nekojin116) is the source of the idea. Don't assume that code is available.

Build:

1. Ctrl+C, Ctrl+X and Ctrl+V on selected text layers via the existing shortcut system, without stealing keys from focused inputs or the on-page text editor. Also context-menu entries in `CanvasContextMenu.tsx`.
2. Copy holds source text, translation, typography including word-level rich text, effects and geometry. Paste creates new layers on the current page at the same position, offset slightly when pasting on the same page. The pasted layers become the selection. One undo step.
3. Clipboard state stays in the app (internal), not the OS clipboard, unless plain translation text on the OS clipboard is trivially safe too.
4. Pasted boxes count as hand-made, so reruns of OCR, translation and lettering never overwrite them. Check how existing hand-added boxes are protected, and don't let a pasted box link to the source box's bubble unless that's correct.
5. Paste goes through a native command (the UI invokes typed commands, native owns durable state) that makes one patch with inverses. Page size differences: clamp the position inside the page.
6. **Agent action:** `copy_text_boxes` with source layers and a destination page.

Tests: payload round trip including rich text, position clamp, shortcut not firing from a focused input.
