# WO-30: Consistent text sizes across a chapter (issue #57, goal #54)

Polished scanlations keep one dialogue size through a chapter; only shouts and titles go bigger. Auto-fit makes each bubble's text as big as the bubble allows, so a short "OK." in a big bubble comes out huge and sizes jump.

Read first: `automatic_maximum` in `koharu-renderer/src/text_renderer.rs`, `SizePart`/`category_style` in `koharu-renderer/src/config.rs`, `commands/lettering/settings.rs`, `TypesettingPreferences.tsx`, rich text's A-/A+ (`commands/rich_text*`), QC's minimum size in `commands/qc.rs`.

Build:

1. **Base size per lettering category**, as a share of page height so it works for any scan size, set in Settings > Typesetting with a preview line. Auto-fit may shrink below it to make text fit (down to the QC minimum), but only grows above it for categories marked "may grow" (Shout, Title and SFX by default). A category with no base size set behaves exactly as today.
2. **Good defaults** that look like typical scanlations. Decide defaults from what the code and typical page heights imply, explain the numbers in a comment, and keep them in the component that owns the category settings.
3. **Chapter check:** after typesetting, dialogue sizes far from the chapter's usual size (median over the chapter's auto-fit dialogue boxes) are pulled toward it, as far as text still fits. One undo step per page. Put the calculation in a pure, tested function.
4. **Priority:** hand-set sizes and word-level A-/A+ always win. Never touch a box the user sized.
5. **Storage:** app settings, plus the existing `extensions` map on Typography for each box's size cap if one is needed. Confirm whether that's a save-format change; it shouldn't be.
6. **All outputs agree:** one prepared frame feeds presentation, PNG, crops and PSD (AGENTS.md); the cap must go through the same layout path, and incremental reuse must match a full render.
7. **Entry point:** a **Make sizes consistent** button for a page or the chapter, as an edit with existing undo. Normal typesetting honours the base sizes too. Don't wire into the auto-run recipe (a sibling branch owns that); expose a function it can call.
8. **Agent actions:** set a category's base size; run the consistency pass on chosen pages.
