# WO-48: Style presets with keys (issue #37)

Roadmap idea: style presets with keyboard keys, for faster hand typesetting. Save the current box's look as a named preset, then apply it to selected boxes with one key.

Read first: `commands/styles.rs`, `lib/text-styles.ts`, `components/preferences/TextStylePreferences.tsx`, `ShortcutPreferences.tsx`, `lib/shortcuts.ts`, `apply_text_style` in `host.rs`, rich text word presets (WO-11).

Build:

1. App-level presets stored with the existing text-style settings (name, font, size mode, colors, outlines, effects, spacing), reusing the existing style part types and numeric color representation. No second format.
2. **Save as preset** from the selection's style controls, and a compact preset list in the Inspector. Click applies to the selection.
3. Keys: up to nine presets on configurable shortcuts in the existing shortcut system (Alt+1 to Alt+9 by default if free). Doesn't steal keys from focused controls or the on-page editor.
4. Applying is one undo step across the selection, and counts as a hand style, so reruns don't overwrite it. With a word selection in the on-page editor, either apply to the words where the style parts allow or do nothing; choose by what rich text supports.
5. Manage presets in Settings: rename, reorder, delete, update from selection.
6. **Agent actions:** list presets, apply a preset to chosen boxes. `list` works in read-only mode.
