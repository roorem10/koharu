# WO-26: Auto run, one button for a whole chapter (issue #65, goal #54)

This is the backbone of the product's main goal: add a chapter, press **Auto run**, get a finished chapter. Build one fixed recipe from steps that already exist, in a shape that later steps (OCR check, cleanup check, QC fix pass, consistent sizes, final look check, and so on, being built on sibling branches) can plug into with small additions.

Read first: `commands/processing.rs`, `commands/runs.rs`, `commands/runs/batch.rs`, `commands/context.rs` and `commands/context/reading.rs` (Read chapter, including how a full run already reads the chapter after OCR, fixed in #55), `commands/lettering*`, `commands/qc*`, `commands/output.rs`, `koharu-pipeline`.

Build:

1. **A recipe type that owns the order.** A native module (for example `commands/auto_run.rs`) defining an ordered list of steps. Each step has an id, a quality level gate, an "is it needed" check, and a run function. Today's steps, in order:
   1. Fix page levels (optional, off by default; raw prep, WO-17)
   2. Detect text, joining boxes that share a bubble (WO-20 setting)
   3. OCR
   4. Read chapter (brief, terms, lettering labels). Skip with a recorded reason when no series is linked or the model can't see images
   5. Translate with context
   6. Clean up
   7. Typeset: category fonts and effects, AI emphasis (what already happens when translations land)
   8. QC
   9. Export (optional, using WO-13's saved export settings; off by default)
   Later steps must be easy to add as one entry each. Add a short ownership comment saying so; do not stub them.
2. **Order rule:** detection and OCR finish on every page before Read chapter starts; after that, translation and cleanup can overlap page by page as today. Reuse the existing job machinery, single job kind, stop path, retries, keep-going and finish chime. Don't add a second cancel path or a second translation prompt path (AGENTS.md).
3. **Quality level**, a persisted setting in `RunSettings` shown on the button: **Fast** (no model requests besides translation), **Balanced** (default; adds Read chapter), **Best** (same as Balanced today; later steps add to it).
4. **One confirm before starting** listing the steps that will run, whether the model can see images, and an estimated number of model requests. For this run it replaces the separate Read chapter confirm.
5. **Safe to run again:** only missing or out-of-date steps run. Hand edits are never overwritten (hand translations, hand styles, hand cleanup, hand-set categories). Translation already skips hand edits; check every other step and enforce the same rule. Write tests for the "is it needed" decisions as pure functions.
6. **Progress by step**: the existing job progress shows the current step name; at the end a short run summary (steps run, skipped steps with reasons, pages, failures, time).
7. **Entry points:** an **Auto run** entry in the Process menu beside the existing ones, and offered as a recipe in the Batch chapters dialog. Manual menus, run presets and single steps stay as they are.
8. **Agent action:** `auto_run` (scope, quality level) in `host.rs`, hidden in read-only mode.
