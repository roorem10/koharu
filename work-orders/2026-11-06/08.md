# WO-08: Rulers, grid and snapping (issue #33)

Batch 4. Neater layouts and faster alignment on the canvas. For anything not specified, match Photoshop or Clip Studio Paint.

1. **Rulers and guides** (upstream koharu `#979`): rulers along the top and left of the canvas in page pixels that follow zoom and pan. Toggle in the View area. Drag from a ruler to create a guide, drag a guide to move it, drag it off the canvas to delete, and a "clear guides" command. Guides are transient view aids, not exported and not visible in PNG/PSD.
2. **Grid with snapping**: show or hide a grid with a size setting. Moving and resizing text boxes snaps to grid lines and guides when snapping is on, with a shortcut to toggle snapping and a hold-modifier to bypass it temporarily, following the existing shortcut system. Don't steal keys from focused controls.
3. **Rotation snap**: rotating a text box snaps to 15 degree steps with Shift held, and to 0/90/180/270 when close, if snapping is on.
4. **Snap a text box to the center of its bubble** (upstream `#941`): while dragging a text box, snap to the horizontal and vertical center of its bubble, with a visible guide line while snapped. Also a command or button "Center in bubble" on the selection, committed as one undo step.

Notes:
- Transient camera, transform and stroke state stay in the browser (AGENTS.md). Guides and grid settings can be per app (app-level preference, or the existing frontend settings store). No save-format change.
- Rich text's on-page editor shares these canvas gestures; don't break it. Snapping must not apply while the on-page text editor is open.
- Rendering of rulers/guides/grid is an overlay in the existing canvas overlay, not in the WASM renderer.
- Put snapping math in a small pure module with unit tests (grid, guide, bubble center, rotation, threshold scales with zoom).
- Agent action: `center_in_bubble` for chosen text boxes (in `host.rs`). Guides are view state, so no agent action for them.
