# WO-38: Agent tab and MCP coverage, part 1: editing features (issue #51)

The in-app Agent and the MCP server should be able to do anything a user can do through direct tool calls. Both use `KoharuHost::tools()` in `crates/koharu-app/src/commands/agent/host.rs`. Add the missing actions below, each calling the same native function the UI's command uses (no second implementation), staying revisioned and undoable, and hidden in MCP read-only mode if they edit.

Add:

- Skew and perspective warp (WO-10, `commands/warp.rs`)
- Box notes (`commands/notes.rs`), and lettering effect compare and reset (WO-06)
- OCR box redo, box reading, and SFX subtitles (WO-07, `commands/ocr_box.rs`)
- Cleanup: remove queue and areas, brush cleanup (WO-15, `commands/cleanup.rs` and `commands/cleanup/`)
- Raw prep and page levels (WO-17, `commands/raw_prep.rs`)

Keep the host file manageable: put new tools' argument types and handlers in the owning feature's module, like `commands::emphasis::agent` and `commands::boxes` already do, and add only one definition line per tool to `tools()` plus its dispatch. Keep tool descriptions short and precise, since every one costs tokens per message. Keep the project summary compact.

Don't add QC list tools (a sibling branch does that) or anything from part 2 (export, run presets, rich text, project and library). Add a focused test where the read-only filter could leak an editing tool.
