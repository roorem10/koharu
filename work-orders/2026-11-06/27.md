# WO-27: Ready check and first-time setup for the auto run (issue #60, goal #54)

The auto run can only be as good as the settings behind it, and today some quiet fallbacks make a first run look bad with no warning: Read chapter is skipped when no series is linked or the model can't see images (`auto_read`, `commands/context/reading.rs`); a lettering category without its own style uses the round-bubble dialogue style (`category_style`, `koharu-renderer/src/config.rs`); models download on first use.

Build:

1. **A native read-only command** `get_ready_check` returning a list of items, each with a status (ready, warning, missing), a reason, and data needed for its fix:
   - Translation model set, and whether it can see images (needed for Read chapter)
   - Target language
   - Series linked to the open project
   - Fonts: which lettering categories have their own font and which fall back to dialogue
   - Models downloaded (detection, OCR, cleanup), with sizes
   - Export when finished: on or off, format, folder
2. **Ready check panel** with each item's status and a **Fix** button that does the fix or opens the exact settings page. Place it in Settings as its own section, built so it can also be opened as a dialog (the auto-run button on a sibling branch will open it before the first run; expose a small component and hook, and open it from a Process menu entry "Ready check" for now).
3. **Series fix:** offer to create a series named after the project or chapter folder, or pick an existing one, reusing the existing series commands.
4. **Models fix:** a **Download all** button reusing the existing model download path, with progress.
5. **Font setup helper:** for each lettering category, suggest installed fonts by name matching (comic, manga, handwriting, bold, and so on), show a preview line, and accept with one click (writes the category's existing style setting). No fonts are bundled. Put the ranking in a pure function with tests.
6. **New chapters remember the series:** a new project offers the last used series, and Batch chapters can link every chapter to a chosen series. Check what batch does today first and extend it.
7. Once every item is ready the check stays out of the way; it only warns when something becomes unset. A small non-modal indicator is enough; don't add a second status counter.
8. **Agent action:** read-only `ready_check` in `host.rs`, available in MCP read-only mode too.
